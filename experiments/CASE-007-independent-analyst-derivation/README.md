# CASE-007 — Independent Derivation from Ambiguous Problems

## Status
Protocol frozen before execution.

## Research question
When independent analysts derive requirements and architecture from the same ambiguous problem description, does an explicit PDI representation improve preservation and agreement of operationally relevant distinctions compared with a competent conventional process?

## Design
Four independent derivations per scenario:
- Conventional A
- Conventional B
- PDI A
- PDI B

No derivation receives the hidden ground truth or another derivation's artifacts.

## Primary measures
- ground-truth distinction recall;
- ground-truth distinction precision;
- inter-derivation agreement;
- downstream capability agreement;
- architecture agreement;
- unsupported assumptions;
- unresolved ambiguities;
- trace completeness.

No overall winner is predefined.
