# CASE-007 Scoring

For each derivation:
- recall = relevant ground-truth distinctions preserved / total relevant distinctions;
- precision = relevant preserved distinctions / all asserted distinctions;
- unsupported assumptions = assertions not supported by the narrative or explicit evidence;
- unresolved ambiguity = ground-truth distinction that remains unresolved where a downstream decision depends on it.

For each condition:
- pairwise distinction agreement;
- pairwise architecture agreement;
- pairwise trace agreement.

No composite score or winner is defined in advance.
