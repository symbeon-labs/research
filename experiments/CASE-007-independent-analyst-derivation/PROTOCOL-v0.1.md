# CASE-007 Frozen Protocol

1. Give only the narrative to each independent derivation.
2. Conventional derivations produce requirements, architecture, assumptions, and traces.
3. PDI derivations first produce a problem representation, then capabilities, architecture, assumptions, and traces.
4. Do not provide the hidden field vocabulary.
5. Do not provide examples of the expected ground truth.
6. Do not allow derivations to inspect each other.
7. Score after all derivations are frozen.

Agreement is computed pairwise within each condition.

Ground-truth scoring uses semantic equivalence classes rather than exact strings.
