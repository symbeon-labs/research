# CASE-006 Results v0.1

## Execution
The frozen pilot protocol was executed on six synthetic ambiguous problems.

## Result
The pilot is **non-discriminating**. Both conditions were given the same deterministic extraction rule and therefore achieved identical scores.

This must not be treated as evidence for or against PDI.

## Methodological finding
The next version must remove any shared distinction oracle from the extraction stage. Independent analysts or independent model runs must infer candidate distinctions from the text without being given the hidden field vocabulary. The hidden ground truth remains available only to scoring.

## Limitation
Synthetic pilot; deterministic extraction; no independent human/model derivation.
