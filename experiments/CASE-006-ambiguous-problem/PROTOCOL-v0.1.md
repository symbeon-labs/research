# CASE-006 Frozen Protocol

For each scenario:
1. Provide only the problem text to both conditions.
2. Condition A extracts requirements and architecture.
3. Condition B first creates an explicit problem representation, then derives capabilities and architecture.
4. Compare both outputs to the hidden ground-truth distinctions.
5. Record all supported and unsupported distinctions.

The ground truth is fixed before scoring.

A distinction counts as preserved only when the output contains enough information to identify it without inference from an unstated assumption.
