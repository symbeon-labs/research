# CASE-002 — Baseline v0.1

## Purpose

The baseline defines a deterministic reference derivation procedure before any representation-loss result is interpreted.

The benchmark does not use a language model in v0.1. This isolates the representation question from model variance.

## Full representation

Each scenario is represented as a structured object containing candidate dimensions:

- objective;
- entities;
- relations;
- sources;
- observations;
- temporal scope;
- constraints;
- authority;
- uncertainty;
- conflict;
- consequences;
- provenance.

## Derivation procedure

The deterministic derivation reads the representation and emits three requirement classes:

1. capabilities;
2. transformations;
3. governance constraints.

A requirement is emitted only when the information needed by the rule is present.

The rules are explicit and versioned.

## Reference requirement set

The full representation is expected to derive a target requirement set for each scenario.

The target is not generated by the reduced representation. It is defined from the complete scenario specification before reduction.

## Representation-loss variants

For each candidate distinction `d`, construct:

`P_minus_d = P_full - d`

or, for a collapse test:

`P_minus_d = collapse(P_full, d)`

No other field is changed.

## Comparison

For each reduced representation, compare:

- reference capabilities vs derived capabilities;
- reference transformations vs derived transformations;
- reference governance constraints vs derived governance constraints.

Record:

- exact matches;
- missing requirements;
- newly ambiguous requirements;
- assumptions required to fill missing information.

## Interpretation rule

A missing requirement is evidence of derivation loss only if the requirement was derivable from the full representation and the reduced representation does not contain equivalent information elsewhere.

This prevents simple field-name dependence from being mistaken for semantic necessity.

## v0.1 boundary

This baseline tests **representation sufficiency for a deterministic derivation procedure**.

It does not yet test:

- language-model performance;
- learned representations;
- domain generalization;
- real-world data;
- optimal representation size.
