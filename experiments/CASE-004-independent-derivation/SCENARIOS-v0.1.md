# CASE-004 Scenarios v0.1

Twelve synthetic problems vary across:
- objective;
- temporal scope;
- source identity;
- entity identity;
- relation;
- constraint;
- authority;
- uncertainty;
- conflict;
- consequence.

Each scenario contains enough distinctions to derive at least three capabilities and corresponding architecture components.

The same semantic problem object is supplied to all four implementations. Input key order and serialization are varied between runs to prevent accidental dependence on representation order.
