# ART-002 — From Problem-Derived Intelligence to Evidence-Governed Resolution

**Version:** v0.1  
**Status:** Draft Research Note / Evolution of Framework  
**Author:** JX-SH1W4  
**Organization:** SYMBEON — Intelligence Systems Lab

## Purpose

ART-002 records the conceptual evolution following ART-001.

The central question is no longer only whether architecture can be derived from problem structure, but what semantic transformations and authority boundaries must be specified before that architecture can be considered operationally valid.

## Current hypothesis

A problem-derived intelligence architecture may need to specify not only capabilities and topology, but also the allowed transformations between observation, evidence, interpretation, resolution, state and action, together with evidence requirements, uncertainty handling and authority boundaries.

## Research status

This is a hypothesis and framework evolution, not an empirical claim.

The complete article will be versioned in this directory as the research series progresses.
